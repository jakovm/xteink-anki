# Security

## Network model

- The add-on starts a **local LAN HTTP server** (default port `5050`).
- Protected endpoints require a bearer / `X-Xteink-Token` API token.
- Intended use: home or trusted network only. **Do not expose the port to the internet** (no port-forwarding, no public reverse proxy without extra auth).

## Token handling

- The API token is generated by the add-on and shown under **Tools → Xteink Status**.
- On the X4 it is stored on the SD card and can be set via CrossPoint web settings.
- Never commit real tokens. The shipped `xteink_sync/config.json` keeps `api_token` empty so Anki generates one locally.

## Firmware flashing

- Published binaries are CrossPoint **1.6.5** builds and are model-specific:
  `crosspoint-1.6.5-xteink-anki-x4.bin` for the ESP32-C3 X4, and
  `crosspoint-1.6.5-xteink-anki-x4pro.bin` for the ESP32-S3 X4 Pro.
- Flashing the wrong device or a different partition map can brick the unit until you recover with a known-good image.

## Reporting issues

Open a GitHub issue. Do not include live API tokens or private collection data in reports.
